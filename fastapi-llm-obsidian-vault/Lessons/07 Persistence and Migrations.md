# Lesson 07 — Persistence and Migrations

## Objective

Persist conversations and messages using PostgreSQL, SQLAlchemy 2.x, and Alembic without scattering SQL through route handlers.

## Initial data model

```text
conversation
------------
id
created_at

message
-------
id
conversation_id
role
content
created_at
model
```

## Architecture

```text
Route → Service → Repository → SQLAlchemy session → PostgreSQL
```

## Migration workflow

```bash
poetry add sqlalchemy alembic asyncpg
poetry run alembic revision --autogenerate -m "create conversations"
poetry run alembic upgrade head
```

Always inspect an autogenerated migration before applying it. Do not manually alter a production schema.
